# Attune roadmap — agreed with Ali on 13 Oct 2026 (read after APP_HANDOFF.md)

This is the direction for every session from now on. Ali's vision: **one everyday app that connects everything in
people's lives — private, fast, smooth and accurate.** AI-powered, but code does the heavy lifting.

## Decisions (don't ask again)
0. **GLOBAL app, not Egypt-only** (Ali, 13 Oct). Egypt/Arabic stay first-class, but every feature is built per
   region: currencies, banks and wallets whose notifications we read, savings circles under their local names
   (جمعية, tanda, susu, chit fund, hui, arisan…), zakat for Muslims anywhere, holidays, units, maps, packs.
   More UI languages after English + Arabic (Spanish, French, Portuguese, Hindi, Indonesian, Turkish, Urdu…).
   The code-first parsers get one rule set per language; Egyptian Arabic is one of them. Examples in UI copy stay neutral.
0b. **Design = direction A "Calm"** (Ali picked it 13 Oct from https://claude.ai/artifact/ES7tU5XVeN4wPDWSPf3wV4):
   soft grey ground, white cards, deep teal accent, one font family + an Arabic partner, a short "Today" summary then
   the areas on Home; bottom bar Home · Chat · Money · Health · Mind; a real wide layout on a computer
   (sidebar + tabs on top + 2–3 columns). Dark mode keeps the same structure.
1. **Sync = sign in with Google + the user's OWN Google Drive (hidden app folder), encrypted on the device.**
   No Attune server, no cloud AI. Data syncs; questions never leave the device. Needs Ali's Google Cloud project
   (OAuth client) and possibly Google's app review for the Drive scope. Replaces "no accounts".
2. **Each device shows what it can really do.** Measure once (RAM, GPU, speed, storage) → a device level.
   Weak phone: no Studio, small models, lighter effects. Strong phone: everything sized to it. Computer: everything,
   big models, full Studio. Same account, same data, different tool list.
3. **Keep EVERY model.** No model is deleted. Auto becomes a router: picks the model by the question (quick, hard,
   photo, code, Arabic, long document) AND the device.
4. **Code first, models second.** Every answer: (1) code looks in the user's data, packs, calculators, web fact
   sheets → (2) code builds an "answer sheet" with sources → (3) the model only writes it up → (4) code checks
   numbers, dates and sources in the answer. Common sentences are parsed by code with no model at all.
5. **Web search stays FREE** (no paid API: nobody can promise Gemini-level, so no per-search cost). Remove Brave
   (reading its pages AND the user-key option). Push free search to the max with code: trusted sites per topic
   (makers, government, price sites), fact sheets, knowledge packs first.
   **UPDATE (Ali, later on 13 Oct): a PAID search API for Pro is fine** "as long as it's as strong as Gemini, the
   answers are like it, and it's covered in Pro". Gate: a test set of real questions (cars, prices, news, Egypt);
   compare Attune's answers with Gemini's; ship the paid API only if it comes close, picking the provider by that
   test (and only one that is legal for a commercial app). Its cost must fit inside the Pro price (cap searches per
   month if needed). Free users keep the free search above. Answer quality also depends on the model: on a computer
   the big models get close; on a phone the code-built fact sheet carries the answer.
6. **Design: professional and minimal.** A design system first (one font, 3 sizes, 8 px grid, one accent, one card
   style, quiet icons), Ali picks a mock-up, then every screen is rebuilt in it — phone AND computer (every page gets
   a real computer layout; Money on desktop is still the phone column today).
7. **Fewer tools:** group about 38 tools into a few areas (proposal in chat 13 Oct: Home/Today, Chat, Money, Health,
   Mind, Files, Places + add-ons Business and Create). Ali agreed in principle; show the final map with the mock-ups. Maps is NOT shown with Money (Ali, 13 Oct) — it belongs to Places.
8. **Prompt improver stays, reworked:** works inside other apps (Android "process text" menu: select text in any
   app → "Improve with Attune"), live tips while typing (wasted tokens, missing format), templates per AI.
9. **Business builder:** complex, fully customisable systems (ERP, invoices, anything) in steps so nobody gets lost:
   describe/template → data (tables, relations, rules) → screens → logic → test with sample data → publish inside
   Attune OR export a real project (frontend + backend + database). Code templates do the work; AI fills the plan.
10. **Learning:** knowledge packs become courses (lessons → quizzes → flashcards with spaced repetition, FSRS).
    Languages: spoken dialogues with offline voices, speaking practice with offline speech recognition and a
    pronunciation score, pictures, code-drawn animated lessons; licensed videos later as packs (commercial-safe only).

## The four big features (Ali: "do all 4 in a professional way")
| Feature | What | Free / Pro |
|---|---|---|
| **Money tracks itself** | Reads bank / InstaPay / wallet notifications (notification access, not SMS — Play restricts SMS) and logs expenses offline; Android only | Free (the daily hook); insights, budgets, reports, export = Pro |
| **Life layer** | Shared data for every tool: People, Money movements, Commitments (installments, bills, subscriptions, جمعية, rent, renewals — dates + checkboxes), Notes/documents, Health. Ali's example: "Ahmed owes me 12,000, 1,000 a month for a year" in Shelf → 12 checkboxes + monthly reminders → each tick = +1,000 in Money; a page per person | Core (people, debts, installments, reminders, zakat) free; جمعية manager, documents vault, routines = Pro |
| **Attune keyboard** | Offline AI keyboard in every app: translate, improve, reply in Egyptian Arabic, prompt-improve | Basic free; replies from your data + prompt coach = Pro |
| **Family circle** | Shared encrypted lists, جمعية, shared expenses, kids' pocket money (over the Drive sync) | Pro |

## Plans (proposal — confirm prices with Ali)
- **Free:** chat (small/medium models, router), free web search, core packs, Money incl. auto-tracking, Life layer
  core, zakat, keyboard basic, Fit basic, 1 map country, 1 course.
- **Pro:** sync across devices, Family circle, big models + Studio, all packs/maps/courses, voice pronunciation,
  routines, reports/exports, keyboard pro, جمعية manager, vault.
- **Business:** the full Business builder, export as a real project, multi-user (over sync).
