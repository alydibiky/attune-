Photos on a document (one or many)

Recommended
  • On any Deadline Radar item (passport, ID, visa, warranty, receipt): Add photo, from the camera or the gallery, as many as you want (front, back, the visa page…).

D2

Details: as many as you want, with ready fields per document

Recommended
  • Each document gets Details, rows of “name: value”. Attune suggests the usual ones for the type, and you can add any other row.
    • Passport: number, issue date, place of issue
    • ID card: ID number
    • Visa: visa number, type, entries, valid from / until
    • Bank card: card number, name on card, expiry, CVC, PIN
    • Account: username, password
  • Each row has a Copy button, handy at an airport form or a website.
  • Search finds them: “my passport number” in Chat or the Radar search answers from here.
  • Say it once: “passport number A12345678, issued Cairo” on the item fills the rows.
