4 · Several AI models together

Models that help each other

A phone AI is limited by memory speed, so two big models running at the same time each go slower. On the phone, the smart way is a relay (one after another). The computer can run a real team.

M1

Router: the right helper for each question

Recommended
Your question→Router
↳“maid now 700” → code, instant
↳“explain this clause” → AI
↳photo → photo model

A tiny model (or code) decides what kind of question it is and sends it to the right tool. Simple things never wait for the AI.

Faster answers and less battery.

Mostly done already by code; this makes it smarter for unclear sentences.

Effort: smallPhone ✓
M2

Relay of specialists

Recommended
📷 Photo modelreads the timetable →
💬 Chat modelbuilds the reminders →
✔ Codechecks times and days
Each does its own job, one after another

Each model does one part in turn: the meaning model finds the passages, the chat model answers, code checks numbers and pages.

Better answers on a normal phone, no memory problems.

Switching big models takes ~5–20 s, so I'd measure on your phone first and use a tiny helper that stays loaded if needed.

Effort: mediumPhone ✓ · Computer ✓

For hard questions (or when you say “check it”), the answer is re-read against its sources and corrected.

About double the time, so only for hard questions.
